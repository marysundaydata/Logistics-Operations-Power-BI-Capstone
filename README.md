🚚 Logistics Operations — Power BI Capstone

📊 Project Overview

A Power BI capstone project built from 14 logistics datasets to analyze different areas of logistics operations and transform raw data into meaningful business insights.

The project involved data cleaning, data modeling, DAX calculations, and interactive dashboard development.

🎯 Dashboards Created

The project consists of four interactive dashboards:

- 🚚 Fleet Health Dashboard — Analysis of fleet condition and operational performance.
- 👨🏽‍✈️ Driver Performance Dashboard — Analysis of driver performance and key operational metrics.
- 💰 Customer Profitability Dashboard — Analysis of customer revenue, costs, and profitability.
- ⏱️ On-Time Delivery Dashboard — Analysis of delivery performance and service levels.

🛠️ Tools & Skills

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization
- Logistics Analytics

📌 Project Scope

The analysis was carried out using 14 logistics datasets, covering different aspects of logistics operations.

The dashboards were designed to help explore operational performance, identify patterns, and communicate insights through interactive visualizations.
